## 1. Project Overview

The purpose of this project was to perform manual
testing of the SauceDemo e-commerce web application.

Testing focused on validating the main customer
shopping journey, from login through successful
order completion.

## 2. Testing Scope

The following modules were covered:

1. Login and Logout Functionality
2. Product Inventory
3. Shopping Cart
4. Checkout Functionality

## 3. Testing Activities Performed

The following testing activities were performed:

- Functional Testing
- Positive Testing
- Negative Testing
- UI Validation
- Form Validation
- Sorting Validation
- Shopping Cart Validation
- Price Calculation Validation
- End-to-End Testing

## 6. Key Findings

### Login

- Valid login worked successfully.
- Invalid credentials were rejected.
- Empty mandatory fields were validated.
- Appropriate error messages were displayed.

### Product Inventory

- Six products were displayed.
- Product information was visible.
- Product images loaded correctly.
- Product sorting worked as expected.
- Product details were accessible.

### Shopping Cart

- Products could be added and removed.
- Cart badge updated after additions.
- Selected products appeared in the cart.
- Cart contents remained available during navigation.

### Checkout

- Checkout navigation worked successfully.
- Valid customer information was accepted.
- Mandatory field validations worked correctly.
- Order overview displayed selected products.
- Price calculations were correct.
- Order confirmation was displayed successfully.

## 7. Defect Summary

No confirmed defects were recorded during the
25 test cases executed.

This conclusion is limited to the tested scenarios
and does not establish that the complete application
is defect-free.

## 10. Final Conclusion

Manual testing was completed for the planned
25 test cases across four application modules.

All recorded test cases passed during execution.

The tested login, inventory, shopping cart and
checkout functionalities behaved as expected.

The application successfully completed the
customer shopping journey during testing.

Further testing is recommended to increase
overall test coverage.
