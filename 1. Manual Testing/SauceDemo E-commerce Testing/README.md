
# SauceDemo E-commerce – Manual Testing Project

## 1. Project Overview

This project demonstrates practical manual testing
of the SauceDemo e-commerce web application.

The objective was to validate the main shopping
journey, including user authentication, product
inventory, shopping cart operations and checkout.

Application: https://www.saucedemo.com/

## 2. Testing Objectives

- Validate login and logout functionality.
- Verify product information and images.
- Test product sorting functionality.
- Validate shopping cart operations.
- Verify checkout form validations.
- Validate order calculations.
- Test successful order completion.
- Verify access restrictions after logout.

## 3. Testing Scope

| Module | Coverage |
|---|---|
| Login and Logout | Authentication and validation |
| Product Inventory | Product listing, details and sorting |
| Shopping Cart | Add, remove, badge and cart contents |
| Checkout | Customer information and validation |
